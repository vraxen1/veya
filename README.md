# VEYA

A responsive concept website for VEYA, a proposed phone and operating-system ecosystem.

## Pages
- `index.html` — brand overview and homepage
- `models.html` — Number, Number Pro, Number Max, Fold and Fold Ultra
- `features.html` — VEYA OS, Action Button, Camera Control, Split Screen, VEYA AI, Veya ID and design concepts
- `pricing.html` — separate page with proposed EUR starting prices
- `styles.css` — responsive visual system and animations
- `script.js` — navigation, scroll reveals and interactive feature previews

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Concept disclaimer
VEYA is an independent design concept, not a currently available phone. Prices are illustrative starting-price proposals. Hardware details that have not yet been defined are intentionally described as design direction rather than confirmed specifications.
